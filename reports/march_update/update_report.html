Март 2026: результат переобучения

Мартовская модель обучена и сохранена отдельно. В приложении оставлена январская модель.

Источник — Turarr, конец марта 2026 года по описанию автора. Дат сбора по строкам нет. Целевая величина — цена предложения, не цена сделки.

На общей независимой от обучения контрольной выборке из 594 мартовских объявлений средняя абсолютная ошибка новой модели увеличилась на 11,3% относительно январской.

Проверка пересечений

  • Совпадений ссылок с январём: 672.
  • Возможных совпадений по характеристикам: 608 (могут пересекаться с совпадениями ссылок).
  • Новых строк после исключения известных групп: 2962.
  • Январская модель на всех этих новых строках: MAE 7,29 млн ₸; ошибка >20% в 25,7% случаев.

Как была проведена проверка

  1. Исходный мартовский файл проверен по SHA256. Пропуски сохранены; цены «от …» не принимаются за точные цены. Сарайшык и Сарыарка остаются разными районами.
  2. Совпадения искались по ссылкам и признакам без цены/состояния: район, площадь, комнаты, этаж, этажность, год и адрес либо ЖК. Все строки одной связанной группы попадают в одну часть.
  3. До оценки и обучения зафиксированы 20% новых групп для test. Остальные мартовские строки используются для обучения с GroupKFold. Январские строки не добавлялись в обучение новой модели.
  4. Сравнены LinearRegression, RandomForest и XGBoost. Семейство и параметры выбирались только по MAE групповой CV. Итоговые модели проверены на общем test без дообучения на нём.

Ограничения

  • Сравнение показывает переносимость январской модели на новый мартовский источник, а также результат обучения на мартовских объявлениях. Изменение ошибки нельзя целиком объяснить изменением рынка: изменились источник и состав выборки.
  • Совпадение характеристик не доказывает идентичность квартир. Неполные признаки и изменения адресов могут скрывать повторы. Проверка не обеспечивает независимость по зданиям.
  • Обновление до марта не делает модель оценкой рынка октября и не добавляет прогноз на шесть месяцев.
  • Диапазон ±MAE остаётся описательным. Его ширина измерена по итоговому test и не является гарантированным интервалом.
